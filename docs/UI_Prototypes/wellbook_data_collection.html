WellBook Data Collection & App Architecture

สถาปัตยกรรมการประยุกต์ใช้อัลกอริทึมทางสรีรวิทยาในระบบดิจิทัล (Implementation Guidelines) และ Data Privacy

📱 แนวทางการพัฒนาซอฟต์แวร์สุขภาวะ (Implementation Guidelines)

1. การคัดกรองอัจฉริยะ (Algorithmic Onboarding)
ระบบต้อง ล็อกเมนูที่มีความเสี่ยงสูงโดยอัตโนมัติ (Hide/Lock) หากผู้ใช้กรอกประวัติโรคที่ระบุไว้ใน Red Flags เช่น หากติ๊กว่ามีความหนาแน่นกระดูกต่ำ (Osteoporosis) ระบบจะบล็อกการแสดงผลคลาส "พิลาทิส" ที่มีท่าก้มหลังทันที
2. การจัดลำดับตามสรีรวิทยา (Session Sequencing)
ในการจัด Bundle แพ็กเกจให้ผู้ใช้ ระบบต้องจัดลำดับอย่างถูกต้อง:
- ลำดับการฟื้นฟู: เริ่มด้วย ซาวน่า (ขยายหลอดเลือด/HSP70) ตามด้วย แช่น้ำเย็น (เร่งกำจัดของเสีย)
- ลำดับการนอน: เริ่มด้วย ฝึกหายใจ (กระตุ้นพาราซิมพาเทติก) ตามด้วย โยคะนิทรา
3. Wearable Integration (ปรับกิจกรรมตาม HRV)
หากดึงข้อมูล Smartwatch แล้วพบว่าค่า HRV ขณะนอนหลับลดลง (ระบบประสาทล้า) ระบบจะปรับ Algorithm ไม่ให้แนะนำการออกกำลังกายหนัก แต่จะแนะนำ Sound Bath หรือ Yoga Nidra เพื่อป้องกันสภาวะ Over-training

🛡️ Data Sensitivity & Liability Protocols

1. No Raw Data Storage (เก็บเฉพาะผลลัพธ์)
แอปจะไม่เก็บข้อมูลกราฟหัวใจหรือคลื่นสมองแบบดิบๆ แต่จะดึงมาคำนวณผ่าน On-device/API แล้วแปลงเป็นตัวแปรสถานะ เช่น HRV_Status = Low เพื่อป้องกันหากเกิด Data Breach ข้อมูลสุขภาพเชิงลึกจะไม่หลุดออกไป
2. Medical Disclaimer (คำเตือนคุ้มครองบริษัท)
ต้องระบุชัดเจน: "WellBook เป็นแพลตฟอร์ม Lifestyle ไม่ใช่เครื่องมือแพทย์" เพื่อปกป้องบริษัทจากการถูกฟ้องร้อง (Liability) และลดความเสี่ยงในการละเมิด พ.ร.บ. สถานพยาบาล
3. Data Decoupling (แยกชื่อออกจากสุขภาพ)
แยกข้อมูลส่วนบุคคล (PII) ออกจากข้อมูลสุขภาพด้วย Hash ID เวลาส่ง Lead ให้สตูดิโอ (B2B) สตูดิโอจะเห็นแค่ "User ID #1042 มีเป้าหมายลดความเครียด" เท่านั้น

📝 1. ข้อมูลจากการสอบถาม (Self-Reported)

  • เป้าหมาย & อาการปวดเมื่อย (Wellness Goals)
    เช่น นอนไม่หลับ, ปวดคอบ่าไหล่, ต้องการฟื้นฟูกล้ามเนื้อ
    ➜ วางรากฐานเพื่อดึงกิจกรรมตาม Biological Mechanism

⌚ 2. ข้อมูลจาก Smartwatch (Wearable Tech)

  • Heart Rate Variability (HRV) & Sleep Data
    ดึงตัวบ่งชี้การทำงานของ Autonomic Nervous System (ANS)
    ➜ นำเข้ากฎ Wearable Integration (ปรับเบา/หนักตาม HRV)

⚙️ WellBook Matching Engine

ประมวลผลผ่าน Algorithm: กรองข้อห้าม ➔ จัดลำดับกิจกรรม ➔ แนะนำ B2B สตูดิโอ

🚫 3. ระบบคัดกรองความปลอดภัย (Algorithmic Onboarding)

  • ข้อห้ามทางการแพทย์ (Absolute Contraindications)
    ลิ้นหัวใจตีบ, กระดูกพรุน, โรคจิตเวชเฉียบพลัน, ลมชัก
    ➜ ทำการซ่อน/ล็อก (Hide) กิจกรรมที่อันตรายแบบอัตโนมัติ

🎯 4. ผลลัพธ์การจับคู่ (Session Sequencing & B2B Match)

  • จัดลำดับแพ็กเกจสุขภาพ & เชื่อมต่อสตูดิโอ
    จัดเรียงกิจกรรมให้ถูกต้องตามสรีรวิทยา (เช่น ซาวน่า แล้วค่อย แช่น้ำเย็น) พร้อมส่งข้อมูลแบบไร้ชื่อ (Anonymized) ให้พาร์ทเนอร์สตูดิโอในไทย
    ➜ นำไปสู่โมเดลรายได้ (B2B Lead Gen & Booking)
