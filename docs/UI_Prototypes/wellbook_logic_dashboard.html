3. Data Collection Breakdown (การจัดกลุ่มข้อมูลที่จัดเก็บ)

Demographics

ข้อมูลพื้นฐานเพื่อจัดกลุ่มและทำความเข้าใจบริบทของผู้ใช้

  • • เพศ (Gender): ชาย, หญิง, ไม่ระบุ
  • • ช่วงอายุ (Age): 18-24 จนถึง 55+
  • • รูปแบบการทำงาน (Work Style): พนักงานบริษัท, เจ้าของธุรกิจ, WFH, นักศึกษา

Health Score

ดัชนีชี้วัดสุขภาพ (Biomarkers & Vetoes) เพื่อความปลอดภัย

  • • อาการทางกาย/ใจ: ปวดเมื่อย, นอนไม่หลับ, เครียด
  • • Vital Signs (Likert 1-5): อัตราการเต้นหัวใจ, เวลานอน, ความถี่ออกกำลังกาย, ระดับความเครียด
  • • Medical Vetoes: ข้อจำกัดสุขภาพ (โรคหัวใจ, บาดเจ็บ)

Preference

ความชอบและวิถีชีวิต เพื่อดึงดูดให้อยากทำกิจกรรม

  • • บุคลิกภาพ: สไตล์กิจกรรม, ความเปิดรับสิ่งใหม่
  • • สังคม (Likert 1-5): ความต้องการพบปะผู้คน (Social Level)
  • • Logistics: สภาพแวดล้อมที่ชอบ, ความสะดวกในการเดินทาง, เวลาว่าง

4. The 5-Dimensional Vector Scoring (ระบบมิติพลังงาน 5 ด้าน)

เราได้ยกระดับอัลกอริทึมจาก Rule-Based เป็น Vector Distance Matching โดยให้คะแนนใน 5 แกนมิติ (แกนละ -5 ถึง +5) เมื่อผู้ใช้ตอบคำถาม ระบบจะสะสมคะแนนทั้ง 5 มิติเพื่อสร้าง "สภาวะปัจจุบันของผู้ใช้" แล้วนำไปเทียบกับกิจกรรมทั้งหมดว่า "ระยะห่าง (Distance) ระหว่างผู้ใช้กับกิจกรรมใดใกล้เคียงกันที่สุด"

Physical
-5: Passive/พักผ่อน
+5: Active/ใช้แรง
Mental
-5: ผ่อนคลายสมอง
+5: ใช้ความคิดเยอะ
Social
-5: ส่วนตัว/คนเดียว
+5: พบปะผู้คน/ปาร์ตี้
Novelty
-5: กิจวัตรเดิมๆ
+5: สิ่งใหม่/สร้างสรรค์
Growth
-5: ไม่มีเป้าหมายชิลๆ
+5: มุ่งพัฒนาตัวเอง

5. The 17-Variable Matrix & Future AI Scaling

แม้จะใช้ระบบสมการ Vector Distance Matching แต่กลไกการจับคู่ก็ยังคงครอบคลุมและแม่นยำที่สุด เนื่องจากระบบดึงข้อมูลถึง 17 ตัวแปรหลัก มาแปลงเป็นมิติพลังงาน และทำการประมวลผลร่วมกัน (Cross-calculation) ในเสี้ยววินาที:

01. Gender (เพศ)
10. Clinical Vetoes (ข้อห้ามทางแพทย์)
02. Age Range (ช่วงอายุ)
11. Activity Style (สไตล์ที่ชอบ)
03. Work Style (รูปแบบทำงาน)
12. Openness (ความเปิดรับสิ่งใหม่)
04. Physical State (สภาวะร่างกาย)
13. Social Level (เข้าสังคม)
05. Mental State (สภาวะจิตใจ)
14. Environment (สภาพแวดล้อม)
06. Resting HR (ชีพจรขณะพัก)
15. Accessibility (การเดินทาง)
07. Sleep Quality (คุณภาพการนอน)
16. Time of Day (เวลาว่าง)
08. Stress Level (ระดับความเครียด)
17. Target Activity (ความต้องการลึกๆ)
09. Exercise Freq (ความถี่ออกกำลัง)

Future ML Scaling

ปัจจุบันระบบเป็น Vector Engine ที่กำหนดน้ำหนักการขยับมิติ (Shift Vector) โดยมนุษย์ เพื่อควบคุมความปลอดภัยทางการแพทย์อย่างเข้มงวด

หากแพลตฟอร์มมี Data ผู้ใช้งานจริงเกิน 10,000 ชุด ระบบจะให้ Machine Learning AI เข้ามาเรียนรู้รูปแบบ และปรับน้ำหนักมิติ (Dynamic Weighting) บนพื้นฐานของพฤติกรรมจริงโดยอัตโนมัติ
