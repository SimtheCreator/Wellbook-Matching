# Wellnista Business Development Atoms

## Atom: User Wants To Own Business Development For Wellnista

Tags: #wellnista #business-development #role  
Source: User request, 2026-06-10  
Status: active

The user wants to act as Business Development for Wellnista. This means the system should help with lead prioritization, partner acquisition, outreach drafts, discovery questions, pilot design, and weekly BD scorecards.

## Atom: Wellnista BD Converts Leads Into Evidence

Tags: #wellnista #bd #validation  
Source: User request and Wellnista project context  
Status: active

The BD role should not only sell; it should convert leads into validated evidence about partner pain, willingness to try WellBook, event collaboration potential, and objections. BD output should feed Product, Operations, and Event strategy.

## Atom: BD Should Use Human-Send Outreach

Tags: #wellnista #bd #outreach #risk-control  
Source: AGENTS.md project rule  
Status: active

Business Development may draft outreach for Instagram, LINE, WhatsApp, Meetup, or email, but sending should remain manual. Contact details must be manually verified before outreach.

## Atom: BD Should Prioritize Community And Small Wellness Organizers First

Tags: #wellnista #bd #icp #partner-acquisition  
Source: AGENTS.md project context  
Status: active

Current Wellnista emphasis is smaller free/community organizers first, then paid booking prospects. Free/community pitch angles should start with discovery, RSVP, attendee list, QR check-in, and community growth, while paid studios should hear booking, payment, capacity, and reduced admin angles.
