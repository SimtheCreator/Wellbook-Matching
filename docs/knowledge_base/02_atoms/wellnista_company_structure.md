# Wellnista Company Structure Atoms

## Atom: Wellnista Should Prioritize Validation Structure Over Formal Org Chart

Tags: #wellnista #company-setup #validation  
Source: AGENTS.md project context and startup operating system guide  
Status: active

Wellnista is currently in a partner acquisition and outreach phase, so the company structure should help validate demand and run outreach. The first structure should be role ownership, scorecard, and weekly decision rhythm rather than formal departments.

## Atom: Community And Paid Segments Need Different Owners Or Pitch Rules

Tags: #wellnista #partner-acquisition #positioning  
Source: AGENTS.md project context  
Status: active

Free or small community groups should be approached with RSVP, discovery, attendee list, QR check-in, and community growth angles. Paid studios and practitioners should be approached with booking, payment, capacity, reduced admin, and launch-offer angles.

## Atom: Human-Sent Outreach Is A Constraint

Tags: #wellnista #outreach #risk-control  
Source: AGENTS.md project context  
Status: active

Instagram, LINE, WhatsApp, or Meetup sending should not be automated. The operating system can draft and track messages, but humans should verify contacts and send outreach manually.

## Atom: Missing Contact Details Are Unknowns

Tags: #wellnista #data-quality #lead-research  
Source: AGENTS.md project context  
Status: active

Missing LINE, email, phone, or IG details should not be treated as verified. The lead process should include manual verification before outreach.
