# Wellnista Operating System Meeting Atoms

## Atom: User Needs A Business Development Meeting Pack

Tags: #wellnista #business-development #meeting #operating-system  
Source: User request, 2026-06-10  
Status: active

The user will meet with Wellnista collaborators and wants to contribute as Business Development. The meeting topics include current company situation, role clarity across three people, KPI/action systems, CEO-to-team delegation, and task tracking.

## Atom: Wellnista Needs A Lightweight Operating System

Tags: #wellnista #operations #okr #tracking  
Source: User request and Foundation Playbook context  
Status: active

The useful system for Wellnista should connect vision to roles, OKRs/KPIs, delegation, task tracking, and weekly review. It should stay lightweight enough for a small team and should avoid becoming corporate bureaucracy.

## Atom: BD Should Frame Itself As Market Evidence Engine

Tags: #wellnista #bd #strategy #validation  
Source: User request and BD skill context  
Status: active

In the operating system meeting, Business Development should be framed as the function that turns partner outreach, discovery, and pilots into market evidence. This helps product, event, and company decisions become less opinion-driven.
