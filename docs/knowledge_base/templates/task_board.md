Use this in a spreadsheet, Notion, Trello, ClickUp, or Markdown table. Keep it simple until volume requires more tooling.

| Task | Project | Owner | Status | Due Date | Output | Blocker |
|---|---|---|---|---|---|---|

## Status Values

| Status | Meaning |
|---|---|
| To do | Not started |
| Doing | Actively being worked on |
| Blocked | Cannot move without a decision or input |
| Review | Waiting for review |
| Done | Output is complete |

## Rule

A task is not real until it has one owner, a due date, and a visible output.
