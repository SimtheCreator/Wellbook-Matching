### Deep Role Card Template

| Field | Fill This |
|---|---|

| Owns | Outcomes, not activities |
| Decides Alone | Decisions inside the role |

| Hands Off | Work this role should not own |
| Weekly Metrics | 2-4 numbers reported every week |

## Prototype 3: CEO Delegation System

### Delegation Flow

```text
CEO priority
-> outcome statement
-> DRI assigned
-> success metric
-> deadline
-> tracker task
-> weekly review
-> decision / unblock / close
```

### Delegation Card

| Field | Example |
|---|---|
| Outcome | Get 10 qualified partner conversations this month |
| DRI | BD |
| Supporting roles | Alice for warm intros, Sim for tracker |
| Metric | 10 conversations, 3 pilot proposals |
| Deadline | Month-end |
| Decision rights | BD chooses lead priority; Alice approves high-stakes partnerships |
| Review cadence | Weekly |

### Decision Rights Rule

- Role owner decides inside their domain.
- If cross-domain conflict appears, debate for 10 minutes.
- If still blocked, CEO decides and logs the decision.
- Once decided, everyone commits.

## Prototype 4: Tracking System

### Recommended Tool

Start with Google Sheet or Notion. Avoid heavy tooling until the team uses the simple tracker consistently for 2-4 weeks.

### Tracker Tabs

| Tab | Purpose |
|---|---|
| Company OKRs | Quarterly objectives and KRs |
| Weekly Priorities | Each person's top 3 priorities |
| Task Board | Owner, status, due date, blocker |
| BD Pipeline | Leads, score, stage, next action |
| Event Metrics | Attendance, revenue, QR signups, learnings |
| Decision Log | One-line decisions and owners |
| Risks / Gaps | Unowned work, bottlenecks, missing resources |

### Task Board Fields

| Field | Description |
|---|---|
| Task | Clear action |
| Project | Tech, Event, BD, Ops, Company |
| Owner | One DRI only |
| Status | To do, Doing, Blocked, Review, Done |
| Due Date | Date |
| Output | What will exist when done |
| Blocker | If blocked, what is needed |
| Next Action | The next physical action |

## Prototype 5: BD Feasibility Machine

### BD Loop

```text
Lead -> Verify -> Score -> Pitch -> Discover -> Pilot -> Learn -> Handoff
```

### Lead Score

Score 1-5:

| Criteria | Question |
|---|---|
| ICP fit | Is this a Thai wellness/community organizer? |
| Admin pain | Do they use manual RSVP, payment, DMs, or attendance tracking? |
| Recurrence | Do they run recurring events/classes? |
| Commitment potential | Could they join a pilot or event collaboration? |
| Access | Is there a verified contact channel? |
| Strategic value | Does this support Tech launch, Event revenue, or event-to-app conversion? |

Decision:

- 24-30: prioritize now.
- 18-23: research or contact if easy.
- 12-17: park.
- Below 12: do not pursue now.
