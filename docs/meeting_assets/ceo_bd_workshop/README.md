# CEO + BD Workshop Pack

Use this pack for a 2-hour workshop between the CEO and Business Development lead.

## Goal

Close the practical startup gaps that keep Wellnista from turning vision into execution:

- unclear ownership
- Alice/CEO bottleneck
- too many ideas without prioritization
- weak connection between vision and weekly action
- no single tracking system
- unclear BD mandate

## Files

- `two_hour_workshop_plan.md` - exact 2-hour agenda with outputs.
- `gap_closing_canvas.md` - worksheet for naming each startup gap and deciding the fix.
- `ceo_bd_agreement.md` - agreement between CEO and BD on ownership, decision rights, and support needed.
- `bd_30_day_sprint.md` - first 30-day BD execution plan and scorecard.

## Expected End State

By the end of the workshop, CEO and BD should have:

1. Agreed which startup gaps matter most now.
2. Assigned owners for each gap.
3. Defined the BD role and decision rights.
4. Set a 30-day BD sprint.
5. Chosen a tracking rhythm and weekly scorecard.
