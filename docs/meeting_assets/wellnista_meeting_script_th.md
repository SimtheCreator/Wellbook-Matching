# สคริปต์ประชุม Wellnista Operating System

## Opening

วันนี้เป้าหมายไม่ใช่ทำให้บริษัทดู corporate ขึ้น แต่ทำให้ทีมเล็กทำงานชัดขึ้น:

- ใครถืออะไร
- วัดจากอะไร
- งานจาก vision กลายเป็น action ยังไง
- ถ้าติดปัญหา ใครตัดสินใจ
- ทุกคนเห็น progress ที่เดียวกันยังไง

## 0. สถานการณ์ตอนนี้

ตอนนี้ Wellnista ไม่ได้ขาด vision แต่กำลังเจอปัญหา execution system:

- มี 2 business units: Tech และ Event
- มีทีมหลัก 3 คน แต่ scope งานใหญ่กว่าทีม
- ownership ยังทับซ้อน
- Alice มีความเสี่ยงเป็น bottleneck
- งานหลายอย่างยังไม่ได้ถูกแปลงเป็น owner, metric, deadline, tracker

ประโยคสำคัญ:

```text
เราไม่ได้ต้องการระบบใหญ่ เราต้องการระบบเบาที่ทำให้ทุกสัปดาห์รู้ว่าใครทำอะไร และธุรกิจเข้าใกล้ vision จริงไหม
```

## 1. Role Split

เสนอให้คุยจาก role ไม่ใช่ ego:

- Alice: direction, brand, key relationships, event revenue, CEO tie-break
- P'Tao: tech build, product reliability, WellBook platform, PDPA/security
- Sim: operations backbone, tracker, growth distribution, event logistics, analytics
- BD: partner pipeline, discovery, outreach, pilot design, market evidence

คำถามที่ต้องตกลง:

1. ใครเป็น Accountable owner ของแต่ละ workstream?
2. งานไหน Alice ไม่ควรถือเองแล้ว?
3. งานไหนยังไม่มีเจ้าของ?

## 2. KPI / OKR System

เสนอให้มี 3 company objectives เท่านั้น:

1. Tech launch and usage
2. Event + partnership revenue/evidence
3. Operating foundation

หลักการ:

- Objective = ทิศทาง
- KR/KPI = ตัวเลขพิสูจน์
- Task = สิ่งที่ต้องทำสัปดาห์นี้

## 3. Delegation From CEO

ทุกงานจาก CEO ต้องไม่ออกมาเป็นคำสั่งลอย ๆ ต้องกลายเป็น Delegation Card:

- Outcome
- DRI
- Metric
- Deadline
- Decision rights
- Review date

ประโยคสำคัญ:

```text
ถ้างานไม่มี owner, metric, deadline งานนั้นยังไม่ใช่งานจริง
```

## 4. Tracking System

เริ่มด้วย Google Sheet หรือ Notion พอ ไม่ต้องใช้ระบบใหญ่

Tabs ที่ควรมี:

- Company OKRs
- Weekly Priorities
- Task Board
- BD Pipeline
- Event Metrics
- Decision Log
- Risks / Gaps

Sim ควรเป็น DRI ของ tracker เพราะเป็น operations backbone

## 5. Ask From The Team

สิ่งที่อยากขอในประชุม:

1. ขอ sign-off role split version 1
2. ขอเลือก tracker tool เดียว
3. ขอให้ทุกคนใส่ top 3 priorities ทุกสัปดาห์
4. ขอให้ BD pipeline เป็น source of evidence สำหรับ product/event decisions
5. ขอ weekly review 30 นาที

## Closing

ถ้าเราทำระบบนี้ได้ดี Wellnista จะไม่ใช่ทีมที่มีแค่ vision ดี แต่จะเป็นทีมที่เรียนรู้จากตลาดทุกสัปดาห์และตัดสินใจเร็วขึ้น
